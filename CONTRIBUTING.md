# Contributing

For code contributions, start at [https://visorvr.com/internals/](https://visorvr.com/internals/); feel free to say hi in `#code-talk` [on Discord](https://go.visorvr.com/discord).

All new contributors will be required to agree to a non-exclusive Contributor License Agreement via https://cla-assistant.io/VisorVR/VisorVR as the current license may be too restrictive for future development. The Contributor License Agreement gives me the ability to relicense VisorVR in the future, for example:

* to use libraries that is not compatible with the current license, e.g. WinUI3 (as of Feburary 2022) or GhostScript (potentially improving PDF support)
* to use artwork that is not compatible with the current license, e.g. GlyphIcons
* to add additional requirements on naming and unique identifiers; as a courtesy, I requested permission from existing contributors in this case, but I was not required to do this under the CLA

**IMPORTANT**: To avoid potential future issues, the CLA is not limited to circumstances like the above; for example, it would hypothetically allow me to relicense future versions of VisorVR under an entirely different license.
