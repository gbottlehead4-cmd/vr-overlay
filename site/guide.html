VisorVR guide

Everything from first launch to a cockpit laid out the way you want it. The same answers live in the app under Help, so you can reach them with your headset on.

Getting started

No installer, no administrator rights.

  1. Unzip it anywhere Keep the folder together — bin, libexec and share have to stay side by side.
  2. Run VisorVR.exe Windows will warn you the app is unsigned. Choose More info → Run anyway. There is no certificate because they cost money every year and this project has none; the full source is public if you would rather build it yourself.
  3. Restart your game VisorVR registers itself with OpenXR when it starts, and a game only picks that up at launch. If the game was already running, it will not see the overlay until you restart it.

Keep VisorVR running. It is not a background service — the app window is what draws your panels. Minimise it, but leave it open alongside the game.

Adding panels

A panel is anything you want floating in the cockpit. Click Add panel in the sidebar and pick a type.

TypeWhat it is for
Web page or dashboardAnything with an address: a SimHub dashboard, a timing screen, a chart, a checklist, a page of your own. The most useful type by a distance.
Desktop windowMirrors a window from your desktop, for apps with no web page of their own. It keeps updating while the game has the screen.
DocumentsPDFs and images. Pick several files and each one becomes its own panel.
Folder of documentsEvery document in a folder, in one panel. Page through them with a bound button.
Endless notebookOne template page, repeated forever — turn the page and you get a fresh copy to write on.
DCS WorldA submenu of purpose-built panels for DCS: aircraft kneeboard, mission briefing, mission kneeboard, radio log and theater kneeboard.

Panels are reordered by dragging them in Settings → Panels, and each one has its own name and icon so the sidebar stays readable once you have a few.

SimHub dashboards

The most common thing people want in here, and the one step that is genuinely hard to guess.

A SimHub dashboard goes in a web panel, so what you need from SimHub is its web address — not the dashboard name, and not SimHub’s own window. SimHub gives you that address in one click, but it lives behind a menu item named for OBS:

  1. Open Dash Studio In SimHub, from the left-hand sidebar.
  2. Choose the Overlays tab Along the top of the Dash Studio screen.
  3. Click the overlay you want So that it is selected.
  4. Click MORE On the right-hand side of that overlay — the button with three lines.
  5. Choose “Copy OBS browser address to clipboard” At the bottom of the menu. It is named for OBS, but it is simply that overlay’s web address and works anywhere.
  6. Paste it into VisorVR Add panel → Web page or dashboard → paste → Add panel.

SimHub has to stay running. The address points at SimHub itself, so when SimHub is closed the panel is blank. Leave it running alongside the game as you normally would.

You do not need to set the panel size by hand: a SimHub dashboard tells VisorVR the size it was designed at, and the panel matches it. If the text looks soft once the panel is in front of you, that is Sharpness, not Size.

Placing panels in VR

The part other overlays make you do with config files: put the headset on and move the panel with your mouse.

Select the panel, then click Edit in VR. Put your headset on. The panel draws its controls on itself while you are editing:

ControlDoes
ClickGrab or drop the panel
Move mouseReposition it
ScrollResize — or change distance while it is grabbed
Shift + moveRotate and tilt
Setup buttonExit and save

Placement is saved per panel and survives a restart, so this is a once-per-panel job rather than something you redo each session.

Cannot see the panel once you are in the headset? Press Recenter, next to Edit in VR. A panel keeps the position you last gave it, so it can easily be behind you, above you, or inside the car — and there is nothing to grab if you cannot see it. Recenter brings it back in front of wherever you are looking now. It is the first thing to try whenever a panel seems to have vanished.

Bind Recenter VR to a button as well, so you can fix it mid-session without taking the headset off.

Making text readable

If small numbers look soft, one setting fixes it — and it is not the obvious one.

Size and Distance change how big a panel looks. They do not add any detail: pulling a panel closer just spreads the same pixels over more of your view. Sharpness renders the page at a higher resolution, the way a HiDPI monitor does, so the text holds together when you lean in.

It runs from 100% to 200%. The ceiling is not arbitrary — panels share one texture with a hard size limit, and going beyond 200% would cost a great deal of video memory for detail your headset cannot resolve anyway.

Sharpness costs GPU time, so raise it on the panel you actually read — a timing screen or a delta — rather than on everything.

Buttons and bindings

Once you are strapped in, the keyboard is out of reach. Bind these before your first session.

Go to Settings → Input, pick your device, click a binding, and press the button you want. Wheel, HOTAS, button box or controller all work.

Bind these three first

BindingWhy
Show/hideTakes the whole overlay off your view and brings it back. The one binding worth having even if you set up nothing else.
Recenter VRPulls your panels back in front of you when they have ended up somewhere you cannot see, without unbuckling to reach the mouse.
Next panelCycles which panel you are looking at, so several panels can share one spot in front of you instead of crowding the cockpit.

Worth binding later

Toggle VR edit modeReposition a panel from inside the headset without going back to the app window.
Next page / Previous pageFor panels holding multi-page documents — charts, plates, a setup sheet.
Increase / Decrease brightnessNight stints, or a panel glaring against a dark track.

Any panel’s settings also has a Set up controller buttons shortcut that takes you straight to the same place.

Troubleshooting

The overlay does not appear in my game

Work down this list — it is ordered by how often each one turns out to be the cause.

  1. Restart the game VisorVR hooks in through an OpenXR layer that is only loaded when the game starts. If VisorVR was not running when you launched the game, or was updated since, the game will not see it until you restart.
  2. Check the layer is switched on Settings → Virtual Reality → “OpenXR support for 64-bit games”. VisorVR registers the layer for your Windows account each time it starts, so this needs no administrator rights.
  3. Check the panel is shown in VR Select it in the sidebar and confirm Show this panel in VR is on. A panel can be visible in the app window and hidden in the headset.
  4. Check it is not behind you Use Recenter. This is the usual answer when it worked yesterday and does not today.
  5. Check your game actually uses OpenXR Some titles default to OpenVR/SteamVR or to a vendor runtime. VisorVR draws into 64-bit OpenXR games only.

A web panel is blank

If it is a SimHub dashboard, SimHub is probably closed — the address points at SimHub itself. Otherwise check the address in the panel settings by opening it in a normal browser: if it does not load there, it will not load here either.

Text is soft or fuzzy

Raise Sharpness, not Size.

Reporting something

In the app: Help → Debugging Information → Save as…, and attach that file to a GitHub issue. It is far more useful than a description. Say which game, which headset, and what you expected to happen.

Files, privacy, uninstalling

Your settings and logs live in %LOCALAPPDATA%\VisorVR, separate from the folder you unzipped. Upgrading by unzipping a new version over the old one leaves them untouched.

Nothing is sent anywhere. VisorVR has no telemetry, no account and no update service. A panel pointed at a web page reaches the internet exactly as a browser would, and nothing else does.

To uninstall: turn off Settings → Virtual Reality → OpenXR support for 64-bit games, then delete the folder you unzipped. The toggle removes the registry entry; without it, one is left behind. Delete %LOCALAPPDATA%\VisorVR too if you want your settings gone.

Getting help

VisorVR is free and open source, made by one person in his spare time. There is no support team.

  • The app’s own Help page carries these answers offline, which matters when you are wearing a headset and have no second screen.
  • Discord — ask other users. Often faster than waiting for me.
  • GitHub issues — bugs and feature requests. Better than Discord for anything that needs acting on, because issues do not scroll away.
